STeaMi Motion Lab — Tutoriel du MVP

La boîte noire du mouvement : une carte instrumentée + un smartphone = un laboratoire sans fil.

1. Matériel

  • Une carte STeaMi avec le serveur BLE motion_lab_server.py (firmware MicroPython + drivers ism330dl, vl53l1x, lis2mdl, wsen_pads, wsen_hids, apds_native, ssd1327).
  • Un smartphone Android avec Chrome récent (Web Bluetooth, Android ≥ 6.0).
  • Un petit chariot / voiture-jouet, une surface plane, un mur ou une plaque verticale.
  • Éventuellement une boîte opaque pour le défi « boîte noire ».

Aucune connexion Internet n'est nécessaire pendant l'expérience.

2. Installer le serveur BLE sur la STeaMi

Copiez motion_lab_server.py vers main.py sur la carte (il démarre automatiquement au boot).

# Windows (remplacez COM3 par le port de la carte)
mpremote connect COM3 cp motion_lab_server.py :main.py

# Linux / macOS
mpremote connect /dev/ttyACM0 cp motion_lab_server.py :main.py

# Puis redemarrez la carte (reset ou debrancher/rebrancher)
mpremote connect COM3 reset

La STeaMi diffuse alors sous le nom ExAOlib (service 8B9D0001-8D4C-4F3A-9B1A-2C3D4E5F6A7B), à 5 Hz. Le BLE démarre même si un capteur est absent.

Note stabilité : le serveur fait une pause de 200 ms par itération pour laisser le stack BLE traiter les connexions. Sans cette pause, le smartphone se déconnecte dès la connexion.

3. Ouvrir l'application sur Android

1
Ouvrez l'application hébergée en HTTPS :
https://acastanet.github.io/steami-motion-lab/motion_lab_app.html
Le Web Bluetooth exige un contexte sécurisé : une page ouverte en file:// ne fonctionnera pas. Pour un accès hors-ligne, ajoutez la page à l'écran d'accueil (« Ajouter à l'écran d'accueil »).
2
Touchez 🔗 Connecter, choisissez ExAOlib dans la liste. L'état passe en « connecté ».
3
Fixez la carte sur le chariot, face au mur. L'acquisition est déjà en cours (5 Hz en continu) : les trois courbes se tracent en direct dès la connexion.
4
↺ Reset efface les courbes pour repartir d'un tracé propre. ⬇ Exporter CSV enregistre la session.

Pas de carte sous la main ? Le bouton 🧪 Demo génère des courbes de démonstration pour tester l'interface, sans la STeaMi.

4. Protocole (référence)

ÉlémentUUIDRôle
Service8B9D0001-8D4C-4F3A-9B1A-2C3D4E5F6A7BExAOlib (Motion Lab)
DATA8B9D0002-…lecture + notify : trame CSV 15 champs

Trame NOTIFY (CSV, 5 Hz, 15 champs) :

ax,ay,az,gx,gy,gz,mx,my,mz,dist,press,temp,hum,temp2,lum
# ax..az : acceleration (g)        gx..gz : rotation (deg/s)
# mx..mz : magnetometre            dist   : distance ToF (mm)
# press,temp : WSEN-PADS           hum,temp2 : WSEN-HIDS
# lum : luminosite (APDS-9960)

L'application Motion Lab utilise uniquement le cœur du MVP (distance + accélération + rotation) :

distance  = champ 10 (dist, mm)
|a| (g)   = hypot(ax, ay, az)
|ω| (°/s) = hypot(gx, gy, gz)

Les autres capteurs (magnéto, pression, température, humidité, lumière) sont transmis mais volontairement ignorés par l'interface MVP.

5. Déroulement pédagogique

Phase 1 — Observer

Lancez l'acquisition et poussez doucement le chariot. Associez le mouvement visible aux changements sur les courbes (distance, accélération, rotation).

Phase 2 — Mesurer

À partir de la distance, la position x(t) donne une vitesse approximée v ≈ Δx / Δt. Comparez l'accélération déduite de la position à celle de l'accéléromètre.

Phase 3 — Prévoir

Avant l'expérience, les élèves prédisent la forme des courbes (immobilité, régulier, accéléré, freinage, choc, rotation, aller-retour), puis confrontent prédiction et mesure.

6. Le défi « boîte noire »

Enfermez la STeaMi dans une boîte opaque. Un élève réalise pendant ~20 s une suite d'actions invisibles (immobilité, déplacement, arrêt, rotation, choc, ouverture). Les autres, à partir des seules données BLE, reconstruisent la chronologie. Chaque capteur devient une source d'indice.

Question clé : quelles données permettent de décider ce qui s'est réellement passé ?

7. Export et exploitation

Avec ⬇ Exporter CSV, l'élève récupère la session (t_ms, distance_mm, ax, ay, az, gx, gy, gz) pour la traiter sous tableur ou Python.

Par niveau : Cycle 4 (distance, durée, vitesse moyenne, chaîne capteur→traitement→communication→affichage) · Seconde (x(t), vitesse, mouvements uniforme/accéléré) · 1re/Tle (dérivation numérique, fréquence d'échantillonnage, bruit, filtrage, incertitudes).
